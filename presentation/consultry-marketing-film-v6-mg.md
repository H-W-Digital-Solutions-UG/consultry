# Consultry — „Die Linie" · MG-first Marketing-Film (73.5s) · v6

Umkehrung von v5: **Motion Graphics sind das primäre Medium**, Live-Action wird Akzent. Der Film spielt auf der warmen dunklen Bühne des Masters, erzählt in der Design-System-Sprache (Cream-Cards, Coral #BF5347, Stone, Mono-Labels, Gradient hero-only). Live-Footage erscheint nur noch in **Evidence-Viewports** — Karten, die sich wie Fenster zur Realität öffnen. Das passt zum Produkt: Consultry IST ein Interface über der Beratungsrealität.

## Leitidee: Die Coral-Linie als Protagonist

Eine 2px-Linie (#BF5347) durchläuft den ganzen Film und wechselt die Rolle: Unterstreichung → Chaos-Faden → Ingest-Strom → Verbindung zwischen Modulen → CitationLink → Chart-Gerade → Signatur. Sie ist die Provenance-Idee des Produkts als Form. Kein Element außer ihr bewegt sich je gleichzeitig mit mehr als einem anderen (Restraint-Regel).

## MG-System-Spezifikation

| Dimension | Regel |
|---|---|
| Bühne | Master-Gradient (warmes Espresso-Schwarz, Vignette) — `ref-hook-gradient.jpg` als Referenz |
| Farben | Coral #BF5347 (Linie/Akzente) · Cream-Cards · Stone-Neutrals · Gradient NUR M4 + M10 |
| Typo | Headlines: Grotesk des Masters · Labels/Badges: Mono, Uppercase, gesperrt |
| Easing | „precise easing": cubic-bezier snaps 300–500ms, keine Bounces, keine Elastics |
| Dichte | max. 2 gleichzeitig bewegte Elemente · Ruhe vor jedem VO-Anker |
| Verbote | kein Glow, keine Partikel im FG, keine 3D-Extrusion, kein Lens-Flare (DS-Restraint) |
| Sound | MG-Ticks/Snaps dezent aus dem SFX-Vokabular (Icon-Pings, Card-Snap, Chart-Draw) unter dem VO |
| fps | 60fps nativ (AE), Match zum Master |

## Warum MG-first zum Produkt passt
