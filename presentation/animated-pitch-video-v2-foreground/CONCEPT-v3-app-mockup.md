# V3 — Feature-Deep App-Mockup Edition (supersedes v2.2 stage-sets)

The scenes are no longer abstract stages: each one is a **screen moment of the Consultry AI web app** — an animated product mockup in the Consultry design system, doing real product things. The film becomes a living product tour behind the slide typography.

## Shared APP SHELL (used by M04–M09)

Espresso-dark app canvas (deep warm brown-black, never grey). **Left icon rail** — slim dark sidebar with 5 abstract glyph tiles, hair-thin coral active-state indicator. **Top bar** — slim, with abstract rounded breadcrumb chips and one circular avatar disc (no face). **Workspace** — matte cream panels on the dark canvas, rounded 12–14px corners, hair-thin coral top borders, 1px stone hairline dividers. **Skeleton-state rows** instead of body text (soft cream-on-cream shimmer bars — webapp-native, not "blurred placeholder"). **Provenance chips** — small pills with coral/stone dots. Layered 2.5D parallax retained: far-plane blurred UI silhouettes behind the app, crisp shell in front. Matte, no glow, no neon. Flat frontal orthographic.

**Text policy (unchanged):** only approved short keywords, spelled exactly — Signal, Team, Angebot, Wissen, Risiken — placed as panel titles. Everything else: skeleton rows, icon glyphs, abstract chips. JSX composites all real copy.

## Why this works with the slides

Same reserved zones as v2.2 (top logo band, per-scene text bands), same freeze-friendly endings, same JSX overlay plan — but the world on screen is now unmistakably a product, not a mood. Feature depth comes from UI density (rail, chips, skeleton rows, live ticks), not from text.
