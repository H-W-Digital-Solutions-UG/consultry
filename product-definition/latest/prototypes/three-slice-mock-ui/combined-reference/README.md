## Exploratory synthesis

[Combined Frame v0.2](./combined-reference-v0.2.png) consolidates useful interaction hypotheses from the explored examples:

- responsibility and concrete effect lead the hierarchy;
- Evidence comparison is embedded in the current Case rather than opened as a separate module;
- current human Challenge Assessment and Materiality remain distinct from the prior human status and the AI Candidate;
- the selected Response transfers directly into an exact Artifact working context;
- the successor remains `Nachfolgeversion · Entwurf` until a real Case assigns its identifier;
- the optional Harness remains a secondary advanced path over the same Case and Authority boundaries.

## Superseded draft

[Combined Exploration v0.1](./combined-reference-v0.1.png) established an earlier example but did not make the current human Assessment/Materiality sufficiently explicit and prematurely showed a fixed `v8` successor identifier. It is retained as Prototype lineage, not as current Product evidence.

## Prototype use

The clickable Three-Slice Mock may use v0.2 as reference evidence, but must not clone it by default. Layout, composition, density, navigation, responsive behavior and scene boundaries remain open to adaptation. What carries forward are the relevant semantic obligations and test hypotheses: exact context, source visibility, distinct AI and human contribution, responsible action, concrete effect boundary and understandable next work.
