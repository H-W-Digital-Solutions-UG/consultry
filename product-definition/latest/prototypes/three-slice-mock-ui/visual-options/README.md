# Consultry Three-Slice Mock UI — Visual Direction Checkpoint

**Status:** Exploratory visual evidence — no layout selected or ratified  
**Date:** 2026-08-05  
**Parent:** [Consultry Three-Slice Mock UI Demo Flow v0.1](../../../Consultry-Three-Slice-Mock-UI-Demo-Flow-v0.1.md)

These three images explore the pivotal Active-Project Challenge scene within the ratified Consultry App Design System v1.1. They are examples for testing information hierarchy, interaction emphasis and Product comprehension. None is a prescribed layout, page template or build target.

## Generated directions

1. [Evidence Decision Workspace](./01-evidence-decision-workspace.png) — strongest direct source comparison and explicit human assessment; risk: can make Consultry feel like a specialized review tool if treated as the global interaction grammar.
2. [Artifact-Centered Challenge Canvas](./02-artifact-centered-challenge-canvas.png) — strongest connection between exact Work Artifact, inline Finding and responsible revision; best fit for Corporate Artifact Alignment and artifact production, but too document-specific as the sole Product grammar.
3. [Responsibility-First Response Workspace](./03-responsibility-first-response-workspace.png) — strongest expression of current responsible work, consequence, boundary and next context; best candidate for the shared Product hierarchy across all three Slices.

## Retained interaction learnings

Do not select one layout for every scene. Retain these learnings as adaptable hypotheses:

- responsibility, consequence and next working context should lead when a human must act;
- exact Artifact work benefits from an Artifact-centered Canvas where the Job requires it;
- source comparison should remain available in the current Case rather than becoming a separate Product module.

These learnings were synthesized in an exploratory [Combined Frame v0.2](../combined-reference/combined-reference-v0.2.png). The synthesis tests whether the exact Case, sources, current human Assessment and Materiality, effect boundary and next context remain understandable together. It does not fix their spatial composition for the clickable Mock.
