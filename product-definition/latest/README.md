| Klasse | Bedeutung |
|---|---|
| **Current Canon** | Aktueller Entscheidungs- und Richtungskern. Auch hier müssen ältere Passagen gegen spätere geschlossene Wayfinder-Entscheidungen reconciliiert werden. |
| **Active Candidate / Input** | Für die Definition relevant, aber nicht automatisch ratifiziert. Liefert Problem-, Journey-, Domain-, GTM-, UX- oder Modulkandidaten. |
