# Specify the existing-client project-sensing journey

## Question

Wie wird eine absichtlich dokumentierte Beobachtung aus laufender Kunden-/Projektarbeit zu einem verantworteten Signal, einer menschlichen Entscheidung und gegebenenfalls einem Commercial-, Delivery-, Change- oder Knowledge-ActionCase — ohne verstecktes Monitoring, automatische Opportunity-Erzeugung oder Incentive auf Signalvolumen?

## Required output

Die Journey folgt dem ratifizierten Journey Contract einschließlich Source Visibility, Owner-/Account-Handoffs, No-Action/Reject/Merge/Reopen, Kunde-/Vertrags-/Projektkontext, Approval vor externer Wirkung sowie Outcome- und Learning-Rückfluss.

## Portfolio placement

Diese Journey ist eine spätere cross-family Intake-/Routing-Vertiefung unter JF-1/JF-2 und keine peer Journey Family. Sie wird nur in voller Tiefe aktiviert, wenn Evidence, Horizon oder ein ausgewählter Slice dies rechtfertigt; eine Observation erzeugt niemals automatisch eine Opportunity.
